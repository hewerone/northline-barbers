Northline Barbers (fictional portfolio concept)

Preview:
- Open index.html in any modern browser.

Before using this for a real client:
- Replace the fictional business name, service list, prices, address and contact details.
- Replace the mailto address with the client's real booking destination.
- Add real, licensed photography and the client's brand assets.
- Confirm all copy, pricing, accessibility, privacy and cookie requirements with the client.
- This demo has no backend booking system or payment processing.

The visual artwork is made from CSS shapes; no external assets are required.
